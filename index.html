Connect Octopus account

Your credentials are stored only in this browser (localStorage) and sent directly to Octopus's API — never to a third-party server.

From your Octopus dashboard → Personal details → API access.
Needed separately because Intelligent Octopus Go dispatch data comes from Octopus's app API (Kraken), not the public REST API — it uses your account login rather than the API key.

Auto-detection picks the first meter point it finds on your account, which can be wrong if you've had a meter exchange. Leave blank to use auto-detection, or fill these in from your Octopus dashboard to override it.

EV notifications

Silent push when charging starts or finishes. Needs a one-time setup: this button subscribes your phone, then you paste the result into a GitHub secret so the checker (running separately on a schedule) knows where to send pushes. See the README for the full setup, including the other secrets it needs.
